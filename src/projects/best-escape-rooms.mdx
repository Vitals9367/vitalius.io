## The Problem

Finding high-quality escape rooms was frustrating and time-consuming. Existing review sites were outdated, lacked filtering options, and didn't offer direct booking capabilities.

## The Solution

I created a comprehensive directory platform that:

- Connects enthusiasts with 4,000+ escape rooms across 10+ countries
- Provides verified reviews from actual players
- Allows to find escape rooms by location, theme, difficulty, or group size
- Provides detailed information about each escape room, including pricing, availability, and a direct booking link

## Tools & Technologies

The platform is built with:

- **Frontend**: Next.js, TypeScript, Tailwind CSS
- **Backend**: Prisma, PostgreSQL, tRPC
